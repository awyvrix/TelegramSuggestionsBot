# Telegram Bot API --- разрешённые эмодзи реакций

Список стандартных эмодзи, поддерживаемых `ReactionTypeEmoji` в Telegram
Bot API (актуально на 21.11.2026).

``` text
❤  👍  👎  🔥  🥰  👏  😁  🤔  🤯  😱  🤬  😢
🎉  🤩  🤮  💩  🙏  👌  🕊  🤡  🥱  🥴  😍  🐳
❤‍🔥  🌚  🌭  💯  🤣  ⚡  🍌  🏆  💔  🤨  😐  🍓
🍾  💋  🖕  😈  😴  😭  🤓  👻  👨‍💻  👀  🎃  🙈
😇  😨  🤝  ✍  🤗  🫡  🎅  🎄  ☃  💅  🤪  🗿
🆒  💘  🙉  🦄  😘  💊  🙊  😎  👾  🤷‍♂  🤷  🤷‍♀  😡
```

## Ограничения

-   Эмодзи должны быть разрешены в настройках реакций конкретного чата.
-   Бот без Premium может установить не более **одной реакции на
    сообщение**.
-   Пользовательские эмодзи (`ReactionTypeCustomEmoji`) --- отдельный
    тип реакции; их можно использовать, если они уже присутствуют среди
    реакций сообщения или явно разрешены администраторами чата.
-   Платные реакции (`ReactionTypePaid`) ботам недоступны.

## Пример (Telegram Bot API)

``` json
{
  "type": "emoji",
  "emoji": "🔥"
}
```
